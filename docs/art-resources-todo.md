### 语音资源前置事项

语音获取安排在资源查询功能开发阶段，当前优先完成静态 Box。不能从资源仓库的 CN 标记推断配音语言覆盖。

- [ ] 明确所需配音语言，核对可靠来源、版本、语言覆盖、下载体积与使用说明。
- [ ] 确认角色 ID、可能的皮肤关联、语言、语音条目 ID 以及文案／名称映射。
- [ ] 独立存放并按需获取资源，记录来源和版本，校验完整性。
- [ ] 检查 QQ、网页与小程序的播放需求，确定格式与转码方案。
- [ ] 原始文件与派生音频分离；资源查询复用索引，各平台负责发送或播放。
