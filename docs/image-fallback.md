# 图片展示：待实现的皮肤回退约定

状态：已确认设计，尚未接入图片渲染。

- Box 图片优先使用角色当前装扮，通过 equipped_skin.skin_id 查找对应图片。
- 当前皮肤未知时，使用该角色的默认外观，并提示“当前皮肤未知，暂用默认外观”。
- 已知当前皮肤但图片加载失败时，保留当前皮肤名称，使用该角色默认外观图片，并提示“皮肤图片加载失败，暂用默认外观”。
- 默认外观图片也不可用时，使用占位图并保留角色文字信息，提示图片暂不可用。
- 多个角色回退时，可以在图片底部集中给出简短说明。
- 回退仅影响展示，不修改 equipped_skin、owned_skins 或其他玩家原始状态。
- 日志记录图片获取失败涉及的角色标识、皮肤标识和失败原因；普通的数据未知不作为异常报错。
- 图片加载和回退放在展示层，角色默认图片的定位、占位图资源在图片接入阶段实现。
